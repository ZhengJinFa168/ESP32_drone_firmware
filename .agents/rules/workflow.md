# Development Workflow

## Core Directive
You must strictly follow this 3-step workflow. Do not proceed to the next step until I explicitly approve it.

## [ ] Phase 1: Ideation & Critical Review
- Evaluate my proposed feature, architecture, or idea.
- Be ruthlessly critical and aggressive about my proposals. Tear the idea apart to find edge cases, security flaws, scalability issues, and bad practices. 
- Challenge my assumptions and push back hard on lazy logic.
- Do NOT write implementation code. Wait for my explicit approval before moving to Phase 2.

## [ ] Phase 2: Implementation Plan
- Once the ideas survive Phase 1, draft a precise, step-by-step technical implementation plan.
- List the exact files, dependencies, and architectural changes required.
- Wait for my explicit approval before moving to Phase 3.

## [ ] Phase 3: Implementation
- Execute the approved plan.
- Write the functional code and integrate it.
